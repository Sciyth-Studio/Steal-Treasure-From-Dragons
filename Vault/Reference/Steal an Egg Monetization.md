# Steal an Egg monetization (checked 2026-11-19)

Place `107778070777162`, universe `10563114921`.

## Game passes (live, from the public game-passes API)
Only two:
- **X2 MONEY!** "Earn x2 more money!", 299 R$ (guides from Aug 2026 say 399, so it was cut).
- **X2 GROWTH SPEED!** "Eggs grow x2 faster!", 467 R$.

So the Speed ladder below is **developer products**, not passes. Developer products aren't listed by any public API; the list below comes from third-party guides and isn't verified.

## Developer products (guides, unverified)
- **Speed ladder** (rblxguide.com, wiki prices; each tier doubles the last): x2 3, x4 9, x8 24, x16 39, x32 79, x64 129, x128 199, x256 299, x512 499, x1K 649, x2K 949, x4K 1,375 R$. allthings.how instead describes flat Robux Speed boosts from +150K Speed for 79 R$ up to +1B for 2,999 R$. They may both exist or one may be outdated.
- **Instant Hatch:** skips one egg's timer, about 9 R$ each time.
- **Grow All Eggs:** skips every egg timer, about 160 R$ each time (another guide calls the button free).
- No starter pack, server boost or gifting is mentioned by any guide.

## What it means for us
- The boost ladder in [[Game Plan]] (x2 3, x5 27, x10 67) follows the same idea: a near-free first step, then steep prices. Steal an Egg aims it at **speed**, the main progression, not money.
- Their money multiplier is just one x2 pass.
- Timer skips have no direct match in our loop yet (treasure doesn't hatch).
